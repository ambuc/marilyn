# marilynjfriedman.com

## Developer tips

Getting started:

```bash
sudo apt install ruby-dev
sudo apt install ruby-bundler
bundle install
```

### Setting symlinks

```bash
ln -s path-to-versioned-file.png shortcut.png
```

### Build and serve

```bash
bundle exec jekyll build
bundle exec jekyll serve
```
